## 2. 디자인/UI/UX 개선 — 최우선

### 2.1 디자인 시스템 통합 (Design System Unification)

**문제**: 앱/웹 모두 컬러, 스페이싱, 타이포그래피가 파편화됨

| 항목 | 현재 상태 | 개선 방향 |
|------|----------|----------|
| **컬러 토큰** | 앱: `AppColors` 하드코딩 / 웹: CSS변수 + Tailwind 혼용 | 시맨틱 토큰 체계 정립 (surface/on-surface/accent/error) |
| **타이포그래피** | 앱: 매 위젯마다 fontSize/fontWeight 직접 지정 / 웹: Tailwind 기본값 | 타입 스케일 정의 (h1~body2, caption) |
| **스페이싱** | 앱: 8/10/12/14/16/20/24px 무작위 / 웹: p-4/p-6/p-8 | 4px 그리드 기반 (4/8/12/16/24/32/48) |
| **Border Radius** | 앱: 8/10/12/14/16/20 혼용 / 웹: rounded-xl/2xl/3xl 혼용 | 3단계 (sm:8, md:12, lg:16, xl:20) |
| **그림자** | 거의 미사용 (flat 디자인) | Elevation 3단계 (low/mid/high) |

**구체적 액션:**
- [ ] `app/lib/theme/app_theme.dart` — TextStyle 프리셋 (h1~caption) + spacing constants 정의
- [ ] `web/src/styles/tokens.css` — CSS 변수 확장 (spacing, radius, shadow 추가)
- [ ] 컬러 팔레트 문서화 (Figma or 코드 내 주석)

### 2.2 앱 Critical UI 수정

#### A. 스켈레톤 로딩 도입 (현재: 모든 화면 CircularProgressIndicator)
**대상**: home_screen, ranking_screen, players_screen, sessions_screen, board_screen
**개선**: 콘텐츠 형태를 미리 보여주는 shimmer skeleton
```
현재: [    ⟳    ]  (빈 화면 + 스피너)
개선: [▒▒▒▒▒▒▒▒▒]  (카드 형태 shimmer)
      [▒▒▒  ▒▒▒▒]
      [▒▒▒▒▒▒▒▒▒]
```

#### B. Empty State 디자인 (현재: 텍스트만)
**대상**: 모든 리스트 화면 (세션, 선수, 공지, 게시판 등)
**개선**: 아이콘 + 설명 + CTA 버튼
```
현재: "참석자가 없습니다"
개선: [👥 일러스트]
      "아직 참석자가 없어요"
      "세션을 만들어 팀원을 초대하세요"
      [+ 세션 만들기] ← CTA 버튼
```

#### C. 에러 UI 통합 (현재: Colors.red vs AppColors.red 혼용)
- `ErrorBanner` 공유 위젯 생성
- `NetworkErrorWidget` — 인터넷 연결 실패 시 전용 화면 (현재: raw exception 텍스트)
- `SnackBar` 스타일 통일 (성공=green, 에러=red, 정보=blue)

#### D. 터치 타겟 수정 (WCAG AA 위반)
- 핀 아이콘 14px → 48dp 영역으로 확장
- 닫기 버튼 16px → 44dp 최소
- 읽지않음 점 6px → 탭 가능 영역 48dp

#### E. 대비 비율 수정 (WCAG AA 미달)
- `Colors.white.withAlpha(102)` (40% 투명도) → `Colors.white.withAlpha(178)` (70%)
- 모든 보조 텍스트 4.5:1 대비 보장

### 2.3 앱 Major UI 개선

#### F. 탭 피드백 & 마이크로 인터랙션
**현재**: `GestureDetector` — 탭 시 시각적 피드백 없음
**개선**:
- `GestureDetector` → `InkWell` (리플 효과)
- 카드 탭 시 `scale: 0.98` 애니메이션 (100ms)
- 골 기록 시 confetti/pulse 효과 추가

#### G. Pull-to-Refresh 개선
- 새로고침 완료 시 `HapticFeedback.lightImpact()` 추가
- 완료 시 짧은 체크마크 애니메이션

#### H. 모달 바텀시트 통일
- 상단 핸들 바 (회색 가로선) 항상 표시
- 타이틀 + 구분선 + 콘텐츠 일관된 구조
- 닫기: 스와이프 다운 + 배경 탭

#### I. 상태 배지 컬러 의미 재정립
```
recruiting → 🟢 green (모집중 — 액션 필요)
closed     → 🔵 blue (마감)
ended      → 🟠 orange (경기완료 — 정산 필요)
completed  → ✅ teal/slate (정산완료)
```

#### J. 폼 UX 강화
- 실시간 유효성 검사 (username 20자 제한 표시)
- `TextInputAction.next` → 다음 필드로 자동 포커스
- 제출 버튼: 로딩 스피너 + 비활성 상태 통일
- 성공 시 SnackBar 피드백 (현재: 무반응)

### 2.4 웹 UI 개선

#### K. ARIA 접근성 (Critical)
- 아이콘 전용 버튼에 `aria-label` 추가
- 드롭다운 메뉴에 `role="menu"`, `role="menuitem"`
- 키보드 내비게이션: Escape로 모달 닫기, Tab 순서 관리
- 색상 의존 정보에 텍스트 대안 추가

#### L. 로딩 스켈레톤 통일
- 일부 페이지만 skeleton 있음 (sessions) / 나머지는 스피너
- 공통 `<SkeletonCard>`, `<SkeletonTable>` 컴포넌트 생성

#### M. 토스트 알림 시스템
- 현재: 액션 성공/실패 피드백 없음 (복사 버튼만 예외)
- `sonner` 또는 `react-hot-toast` 도입
- 세션 생성, 선수 추가, 삭제 등 모든 mutation에 피드백

#### N. 브랜드 컬러 일관성
- `emerald-500` vs `brand-green` 혼용 → `brand-green` 통일
- Tailwind config에서 `emerald` → `brand` alias 설정

#### O. 반응형 개선
- 랭킹/선수 그리드: 태블릿 가로에서 레이아웃 깨짐
- 관리자 페이지: 모바일에서 사이드바 없이 접근 불가
- 세션 상세 탭: 비활성 탭에 왜 비활성인지 툴팁 필요

### 2.5 앱 전용 디자인 신규 기능

#### P. 라이트 모드 제대로 구현
**현재**: `ThemeMode.system` 설정돼 있지만 모든 화면이 다크 모드 하드코딩 (`Colors.white`, `AppColors.bgBase`)
**개선**:
- `Theme.of(context)` 기반으로 동적 컬러 사용
- 라이트 모드용 시맨틱 컬러 정의 (bgBase → scaffold, bgCard → card)
- 현실적으로 전체 리팩은 대공사 → **우선순위: 중-하** (다크 모드 사용자 위주)

#### Q. 페이지 전환 애니메이션
- 현재: 기본 MaterialPageRoute (밋밋함)
- 개선: shared element transition (선수 카드 → 상세), fade through

#### R. 온보딩 플로우 (미착수 확인됨)
- 첫 사용 시 3~4단계 소개 (세션 만들기 → 팀 편성 → 경기 기록 → 랭킹 확인)
- 코치마크: 첫 세션 생성 시 "여기를 탭하세요" 오버레이
- 빈 홈 화면일 때 퀵스타트 가이드 표시

## 3. 게이미피케이션 & 리텐션

### 3.1 배지/업적 시스템 (경쟁사 분석 기반 — 리텐션 +30% 예상)

| 배지 | 조건 | 아이콘 |
|------|------|--------|
| 첫 골 | 첫 번째 골 기록 | ⚽ |
| 해트트릭 | 한 경기 3골 | 🎩 |
| 수비왕 | 한 경기 수비 5회 | 🛡️ |
| 출석왕 | 한 시즌 출석률 90%+ | 📅 |
| 100경기 | 누적 100경기 참여 | 💯 |
| 연승 | 3연승 달성 | 🔥 |
| 올라운더 | 골+어시+수비 모두 기록 (단일 세션) | ⭐ |
| MVP | 세션 MVP 선정 | 🏆 |

**필요 작업:**
- DB: `player_badges` 테이블 (player_id, badge_type, earned_at, season)
- API: 경기 완료 시 자동 배지 체크 + 알림
- 앱: 프로필에 배지 그리드, 획득 시 팝업 애니메이션
- 웹: 선수 상세에 배지 표시

### 3.2 출석 스트릭 (Streak)

- 연속 출석 횟수 추적 (현재 DB에 로직은 있으나 UI 없음)
- 홈 화면에 "🔥 5연속 출석 중!" 배너
- 스트릭 깨지면 "지난주 놓쳤어요. 이번 주 다시 시작!" 격려 메시지
- API: `stats.ts`의 streakResult 활용

### 3.3 시즌 어워드

- 시즌 종료 시 자동 시상: 득점왕, 수비왕, 출석왕, MVP, 최다 어시, 신인상
- 명예의 전당 (hall_of_fame_screen.dart) 확장
- 시상식 결과 공유 카드 (이미지 생성 → 카톡/인스타 공유)

### 3.4 주간/월간 챌린지

- "이번 주 수비 챌린지: 팀 전체 수비 20회 달성"
- 클럽 단위 목표 → 달성 시 전원 배지 획득
- 관리자가 커스텀 챌린지 생성 가능

## 4. 기능 개선 & 신규 기능

### 4.1 경기 결과 공유 강화 (사용자 기존 요청)

**현재 상태**:
- 앱: `MatchResultPopup` 존재 — 작동 확인 필요
- 웹: `stats-tab.tsx`에 이미지 캡처 + 텍스트 복사 존재 — 렌더링 확인 필요

**개선:**
- 앱: 공유 카드 디자인 개선 (현재 기본적) → FotMob 스타일 매치 카드
- 웹: 공유 링크 생성 (공개 URL로 접근 가능한 매치 결과 페이지)
- 카카오톡 공유 SDK 연동 (앱)
- 인스타그램 스토리 공유 (앱)

### 4.2 라이브 스코어 공유 (경쟁사 대비 기회)

- 경기 진행 중 실시간 스코어 확인 가능한 공개 URL 생성
- 가족/친구가 앱 없이도 브라우저에서 확인 가능
- QR 코드 생성 → 구장에서 스캔
- **구현**: 기존 이벤트 기록 시스템 활용 → 읽기 전용 공개 뷰 추가

### 4.3 포메이션/라인업 시각화

- 세션 상세 → 팀 구성 탭에 필드 위 선수 배치 시각화
- 드래그 앤 드롭으로 위치 지정 (관리자)
- 미니 축구장 SVG 위에 선수 아바타 배치

### 4.4 세션 템플릿 & 반복

**현재**: 매번 새로 생성
**개선**:
- "이전 세션 복사" 버튼 (날짜만 변경)
- 반복 세션 (매주 화/목 21시) 자동 생성
- 기본 장소/시간/인원 프리셋

### 4.5 인앱 채팅 (장기)

- 세션별 채팅방 (경기 전/후 소통)
- 클럽 전체 채팅방
- 카카오톡 대체 목표
- **기술**: Cloudflare Durable Objects 또는 외부 채팅 SDK

### 4.6 푸시 알림 (Critical Gap)

**현재**: DB 기반 폴링만 존재
**필요**:
- Firebase Cloud Messaging (FCM) — Flutter 앱
- Web Push API — 웹
- 알림 유형별 on/off 설정 (사용자 환경설정)
- 긴급 용병 모집 시 푸시 알림

### 4.7 사용자 프로필 관리

**현재 API에 없는 것:**
- 프로필 사진 변경
- 비밀번호 변경/리셋
- 계정 삭제 (GDPR/개인정보보호법)
- 폰번호/생년월일 수정 (DB에 컬럼은 존재하나 API 없음)

### 4.8 댓글 편집/삭제

- 현재: 댓글 생성만 가능, 수정/삭제 불가
- 본인 댓글 수정 + 삭제 API 추가
- 관리자 댓글 삭제 (모더레이션)

### 4.9 게시글 반응 (이모지 리액션)

- 현재: 댓글만 가능
- 개선: 👍❤️😂🔥 등 이모지 반응 추가 (카톡 스타일)
- 게시글 + 댓글 모두 적용

## 5. API & 인프라

### 5.1 검색 기능 확장

| 현재 | 개선 |
|------|------|
| 선수 검색 없음 | 이름/닉네임 검색 + 포지션 필터 |
| 세션: status만 필터 | 날짜 범위 + 장소 + 제목 검색 |
| 게시글: category만 필터 | 제목/내용 FTS |

### 5.2 캐싱 전략 개선

- 랭킹 캐시: 세션 완료 시 자동 갱신 (현재: 수동 refresh만)
- HTTP Cache-Control 헤더 추가 (GET 요청 — stale-while-revalidate)
- 선수 목록 캐싱 (현재: 매 요청마다 전체 조회)

### 5.3 페이지네이션 통일

- 현재: 일부만 limit/offset, 일부는 전체 조회
- 모든 리스트 API에 cursor-based pagination 도입
- 앱/웹에서 무한 스크롤 또는 "더보기" 지원

### 5.4 이미지 처리 개선

- 현재: 원본 그대로 업로드 (2MB 제한)
- 개선: 서버사이드 리사이즈 (thumbnail 300px, medium 800px)
- WebP 자동 변환
- EXIF 스트리핑 (개인정보 보호)

## 6. 보안 & 안정성

### 6.1 Critical

| 항목 | 현재 | 개선 |
|------|------|------|
| **Rate Limiting** | 없음 | 로그인: 5회/분, API: 100회/분 |
| **JWT 만료** | 30일 | 7일 + Refresh Token 도입 |
| **출석 중복** | UNIQUE 제약 없음 | `UNIQUE(session_id, player_id)` 추가 |
| **입력 검증** | 부분적 | Zod 스키마 전체 적용 |

### 6.2 Medium

- 사용자 생성 콘텐츠 XSS 방지 (HTML 이스케이프 확인)
- Admin RBAC 프레임워크 (현재: 하드코딩 role 체크)
- Soft delete (posts, comments — 현재 hard delete)
- 감사 로그 (관리자 액션 기록)

## 9. 확인 필요 사항 (질문)

다음 사항들은 구현 전에 결정이 필요합니다:

### 디자인
1. **라이트 모드**: 현재 앱은 다크 모드 하드코딩인데, 라이트 모드도 정식 지원할 건지? 전체 리팩이 필요해서 대공사임. 다크 전용으로 갈지?
2. **앱 아이콘/스플래시**: 현재 기본 아이콘인데, 브랜드 아이콘 디자인 있는지?
3. **Figma 디자인 파일**: 기존 디자인 시안이 있는지? 없다면 디자인 시스템부터 새로 잡을지?

### 기능
4. **채팅 우선순위**: 세션별 채팅이 카카오톡 그룹채팅을 대체할 만큼 가치가 있는지? 사용자들이 원하는지?
5. **배지 시스템 범위**: 간단하게 (5~8개 배지) vs 풍성하게 (20개+, 레벨 시스템 포함)?
6. **라이브 스코어**: 공개 URL 허용 시 비공개 클럽 데이터 노출 우려 — 허용 범위는?
7. **앱 이름**: "코너킥스" 유지 vs 범용 이름으로 변경 (기존 메모에 "범용 이름으로 변경 예정"이라 있음)

### 인프라
8. **푸시 알림**: Firebase 프로젝트가 이미 있는지? 새로 생성해야 하는지?
9. **출시 타겟**: 플레이스토어만? 앱스토어(iOS)도?
10. **수익 모델 결정**: 현재 Pro 구독이 있는데, 배지/게이미피케이션을 Pro 전용으로 할지 전체 공개할지?
